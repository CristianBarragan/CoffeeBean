# Foundgine.Intent.Json

Thin JSON input adapter.

It parses structured read intent and converts it into Foundgine's canonical semantic request. Resolution, authorization, planning, and execution happen elsewhere.
## Install

```bash
dotnet add package Foundgine.Intent.Json
```

## Package scope

Treat JSON intent as untrusted input. Parsing is only the first step; resolution, authorization, planning, and execution remain separate stages.
