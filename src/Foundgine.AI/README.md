# Foundgine.AI

Provider-neutral AI agent integration for Foundgine using `Microsoft.Extensions.AI`.

## Agent flow

```text
User
  |
  v
AI agent
  |
  +-- foundgine_capabilities
  |
  +-- foundgine_query
           |
           v
      ReadIntent
           |
      resolution
           |
      authorization
           |
         plan
           |
       provider
           |
         result
```

`FoundgineAiAgent` wraps any `IChatClient` with Foundgine tools and a bounded
function-calling loop. The model chooses tools, but the host application owns
`ExecutionContext`; tenant, identity and authorization values are never tool
arguments.

## Usage

```csharp
var toolset = new FoundgineAiToolset(
    foundgine,
    contextFactory: () => currentExecutionContext);

var agent = new FoundgineAiAgent(chatClient, toolset);
var response = await agent.RunAsync(
    "Show me customers with accounts over $5,000");

Console.WriteLine(response.Text);
```

The implementation uses `FunctionInvokingChatClient` and limits each request to
a small number of tool iterations. Foundgine still re-validates, authorizes,
plans and executes every query.


## Capability contract

`foundgine_capabilities` exposes the canonical semantic capability contract generated by Foundgine. The contract is derived from the same semantic model and authorization policy used by execution. It is discovery metadata, not an authorization bypass; every submitted intent is authorized again at execution time.

The contract is designed to become the shared source for agent discovery, MCP, GraphQL, JSON and other transports rather than maintaining separate tool schemas.


## Security boundary

AI tool calls are treated as untrusted input. Capability discovery and query execution require a host-supplied `SecurityExecutionContext`; the model cannot provide or override subject, audience, tenant, resource scope, or warrant. The same Foundgine warrant, authorization, planning, proof, provider-conformance, and execution pipeline is used for AI calls and direct callers.
