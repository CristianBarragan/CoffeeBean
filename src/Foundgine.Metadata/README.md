# Foundgine.Metadata

Describes the application's static model: entities, fields, relationships, identities, and storage mappings.

Metadata says **what exists**. It does not resolve requests or generate SQL.
## Install

```bash
dotnet add package Foundgine.Metadata
```

## Package scope

Metadata describes the semantic and storage facts needed by the runtime. It does not grant authorization or execute requests.
