# Foundgine.Execution

Defines the provider execution boundary and result materialization.

It consumes provider-independent plans and uses the semantic model to rebuild results. Physical provider details stay in provider projects.
## Install

```bash
dotnet add package Foundgine.Execution
```

## Package scope

This package is the runtime provider boundary. Providers consume the provider-independent plan; the semantic and planning layers remain provider-neutral.
