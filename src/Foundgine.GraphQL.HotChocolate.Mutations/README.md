# Foundgine.GraphQL.HotChocolate.Mutations

GraphQL mutation adapter.

It translates GraphQL mutation input and result selections into Foundgine mutation intents and result shapes. Planning and execution remain provider-neutral.
## Install

```bash
dotnet add package Foundgine.GraphQL.HotChocolate.Mutations
```

## Package scope

This package is a transport adapter. GraphQL input is not authorization: mutation intent still passes through Foundgine semantic authorization and planning before physical execution.
