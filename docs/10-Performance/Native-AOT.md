# Native AOT

Native AOT is a future compatibility goal, not a current verified claim.

## Architecture that helps

Foundgine favors:

- explicit metadata;
- deterministic plans;
- provider contracts;
- limited runtime discovery;
- compile-time semantic generation as a future direction.

## What remains

Formal Native AOT verification has not been completed for the active solution.

Do not describe Foundgine as Native-AOT compatible until a published AOT build/test proves it.
