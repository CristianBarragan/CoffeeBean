# M0.15 — AOT Boundary Freeze

## Purpose

Freeze the AOT boundary after the M0.x architectural cleanup.

AOT is compile-time infrastructure. It discovers domain declarations with Roslyn and emits the same metadata contracts consumed by the runtime path. It does not define semantic, planning, execution, SQL, or GraphQL behavior.

## Boundary

```text
Domain source
    ↓
Roslyn incremental generator
    ↓
Generated Foundgine.Metadata
    ↓
M1–M5 runtime path
```

The generator may reference the metadata contracts because its job is to produce metadata. The runtime engine does not depend on the generator implementation.

## M0.15 correction

The relationship emitter must preserve semantic source/target direction regardless of which side owns the foreign-key property.

For a collection relationship:

```text
Customer → Accounts
Customer.Id → Account.CustomerId
```

`SourceKey` is `Customer.Id` and `TargetKey` is `Account.CustomerId`.

For a reference relationship where the source owns the foreign key:

```text
Account → Customer
Account.CustomerId → Customer.Id
```

`SourceKey` is `Account.CustomerId` and `TargetKey` is `Customer.Id`.

The generator now determines the foreign-key owner and emits the key mapping accordingly.

## AOT non-goals

The generator does not generate:

- SQL
- provider plans
- execution nodes
- GraphQL types
- runtime reflection-based discovery
- provider-specific abstractions

## Acceptance

1. Generated metadata implements the existing metadata contracts.
2. Generated relationships preserve semantic source/target direction.
3. Both principal-owned and source-owned foreign-key relationships are covered by tests.
4. The runtime path does not require the generator assembly.
