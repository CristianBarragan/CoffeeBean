# M9 — Result Materialization

M9 reconstructs the provider-neutral semantic result tree from flat execution rows.

Providers retain their existing diagnostic `Values` map, but also emit stable
`ExecutionCellKey` values (`NodeId`, `EntityId`, `FieldId`). `ResultMaterializer`
uses those identities plus the semantic model's identity field to collapse
repeated relational rows into semantic nodes and attaches child nodes by
relationship identity.

No SQL, GraphQL AST, or CLR entity construction is introduced into the
materialization contract.
