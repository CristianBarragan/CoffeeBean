# M7 — GraphQL Adapter

M7 proves that GraphQL is an adapter over Foundgine rather than the engine itself.

```text
GraphQL
   ↓
Hot Chocolate AST
   ↓
SemanticRequest
   ↓
Resolve → Authorize → Plan → Provider
```

The adapter is the only active project in Foundgine that references Hot Chocolate.

## Porting rule

The archived Graphgine/HotChocolate adapter was used as a reference for one proven technique: walk the Hot Chocolate selection AST and translate it into a protocol-neutral intermediate request. Its old `SelectionIR`, mutation IR, connection wrappers, filtering, ordering, and runtime execution types are not migrated.

## M7 scope

Supported:

- one query operation
- one root field
- scalar field selections
- relationship selections
- inline fragments without type-specific semantics
- GraphQL camel-case mapping such as `customer` → `Customer`
- GraphQL `__*` meta-fields are ignored

Deferred:

- named fragments
- directives / conditional selection
- mutations
- arguments / variables
- filters
- ordering
- pagination
- subscriptions
- Relay connection wrappers
- aliases in the semantic result model

These are deferred because the current `SemanticRequest` does not yet represent them. Adding them merely to match the old adapter would violate the porting rule.
