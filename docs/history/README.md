# History

Historical design notes and milestone documents are kept here so the active documentation stays small.

- `direction/` — architecture and product decisions
- `status/` — old status snapshots and boundary freezes
- `root-milestones/` — former root-level milestone and port notes
- `source-notes/` — notes that used to live beside source files

These files explain history, not current behaviour. Use `docs/CURRENT-STATUS.md` for the current state.
