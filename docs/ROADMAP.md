# Roadmap

The foundation is intentionally small. The next work should improve usefulness without weakening the boundaries.

## Near term

- simplify public APIs where the current contracts are more complex than necessary;
- improve provider composition and real-world examples;
- measure end-to-end performance;
- keep GraphQL and JSON adapters thin;
- document only capabilities that are implemented and tested.

## Later

Potential work includes more providers, richer semantic actions, and stronger AI/agent integration.

These are ideas, not current capabilities.
