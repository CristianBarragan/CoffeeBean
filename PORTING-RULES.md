# Porting Rules

CoffeeBeanery V2 and Graphgine are archived proof/reference implementations.

For every candidate concept from the archives:

- KEEP only if the current Foundgine architecture needs the capability.
- REIMPLEMENT when the old implementation is useful but the abstraction does not fit.
- IGNORE when the capability is unnecessary or duplicates a simpler Foundgine concept.

Never copy an old project wholesale. Never preserve a type solely for compatibility with the archive.
