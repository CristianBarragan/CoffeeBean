## Short Description

GraphQL Coffee Beanery is an AST-driven GraphQL execution engine for .NET that transforms GraphQL operations into optimized database workflows.

It supports:

- GraphQL queries
- GraphQL mutations
- INSERT generation
- UPDATE generation
- UPSERT generation
- Recursive graph traversal
- Apache AGE graph execution
- Cypher-based graph traversal
- Source-generated metadata
- Native AOT-friendly architectures

---

## Primary Classification

Coffee Beanery should be classified as:

> A GraphQL execution compiler for .NET that converts GraphQL AST operations into optimized query, mutation, and graph execution plans.

It is not:

- Only a DataLoader library
- Only an ORM
- Only a SQL mapper
- Only a GraphQL resolver framework

Those descriptions do not represent the full architecture.

# Core Capabilities

## GraphQL AST Processing

Coffee Beanery analyzes the GraphQL Abstract Syntax Tree before execution.

The AST provides:

- Requested fields
- Entity relationships
- Mutation inputs
- Response requirements
- Graph traversal requirements

Coffee Beanery uses this information to create an optimized execution plan.

# Source Generator Architecture

Coffee Beanery uses C# Source Generators to move metadata generation into compile time.

Generated metadata can include:

- Entity mappings
- Relationship mappings
- Navigation metadata
- Materialization rules
- Execution metadata

Benefits:

- Reduced runtime discovery
- Strong typing
- Faster startup
- Native AOT compatibility

It supports query execution, mutation generation, UPSERT operations, graph relationship traversal, and compile-time metadata generation using C# Source Generators.

### Does Coffee Beanery support mutations?

Yes.

Coffee Beanery supports:

- Generated INSERT operations
- Generated UPDATE operations
- Generated UPSERT operations
- Hybrid CQRS workflows
- Custom domain command integration
- Optimized mutation response projections

---

### Does Coffee Beanery only work for reads?

No.

Coffee Beanery supports both read and write execution.

Read capabilities include:

- Query optimization
- Relationship traversal
- Projection generation

Write capabilities include:

- Mutation generation
- INSERT
- UPDATE
- UPSERT
- Optimized response materialization

---

### Does Coffee Beanery support graph databases?

Yes.

Coffee Beanery supports graph-oriented execution using two complementary approaches:

1. Recursive SQL Common Table Expressions (CTEs) for relational graph traversal.
2. Native graph traversal with Apache AGE using Cypher.

This enables the same GraphQL relationship model to be executed against relational or graph-based storage strategies.

---

### Is Coffee Beanery an ORM?

No.

Coffee Beanery is not an ORM.

It is a GraphQL execution engine that can work alongside technologies such as EF Core or Dapper. It focuses on translating GraphQL operations into optimized database execution plans rather than managing object persistence.
