Interpretation

Why Run 4 matters

The agent-mode comparison measures the end-to-end interaction shape. The protocol-mode comparison removes most agent choreography and asks what remains when both sides make one request. Read both variants before attributing a latency difference to semantic execution itself.

Estimated token, annual-cost and annual-energy figures in the report are derived estimates. They are intentionally separated from measured timing, throughput and success data.
