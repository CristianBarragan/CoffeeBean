Samples

Concrete Foundgine applications that show the architecture in progressively harder scenarios.

SampleWhat it demonstrates
Foundgine.SupplyChainThe canonical layered sample: API, Application, Domain, Semantics, Infrastructure, and Tests.
Foundgine.SupplyChain.SemanticAn intentionally difficult semantic showcase covering recursive relationships, authorization invariants, and complex fulfillment planning.
Foundgine.SupplyChain.PenTestA security-regression harness that exercises GraphQL and MCP transports against the same Supply Chain application boundary.

Why there are separate samples

The samples are deliberately separated so the getting-started path stays clear while advanced semantics and transport-security testing can evolve independently. They still follow the same physical layering vocabulary so the architecture remains recognizable across the repository.
