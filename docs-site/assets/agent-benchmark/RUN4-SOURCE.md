# Run 4 source note

Published Run 4 data is generated from `assets/agent-benchmark/run4/`. The interactive explorer reads `benchmark-matrix.json`.

Measured: tool calls, estimated context-load tokens, latency, RPS, success/failure counts.
Derived: USD cost, energy and CO2e. The explorer exposes all assumptions.

Run 4 matrix: 4 workloads (10/100/1,000/10,000 customers) × 4 concurrency tiers (8/16/32/64), 30 measured runs after 5 warmups.
