Repository walkthrough

Start with one request.

The fastest way to understand Foundgine is to follow a small semantic request through resolution, authorization, planning, and execution.

Requirements

  • .NET 9 SDK
  • Git
  • Docker and Docker Compose for PostgreSQL integration tests

Build and test

dotnet restore Foundgine.sln
dotnet build Foundgine.sln --configuration Release
dotnet test Foundgine.sln --configuration Release

PostgreSQL-backed tests are environment-dependent. Set FOUNDGINE_POSTGRES_CONNECTION_STRING when running the local database integration path.
